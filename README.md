# 🌤️ Interactive Weather Cards UI

A clean, aesthetic, and responsive **Weather Cards UI design** built from scratch using **HTML5** and **CSS3**. This project focuses on card-based layouts, custom positioning, and smooth styling for multiple city weather panels.

---

## 🚀 Features

* **Card-Based Layout**: Designed with multiple styled weather cards showcasing different cities (Karachi, Lahore, Islamabad)[cite: 9].
* **Search Bar Elements**: Custom input fields and search icons integrated into each card header[cite: 9].
* **Dynamic Details**: Displays temperature metrics, weather conditions, humidity percentages, and wind speeds[cite: 9].
* **Aesthetic Styling**: Soft gradients, rounded container shapes, and a cloudy sky background theme for a modern visual feel[cite: 9].
* **Pure Frontend**: Built entirely with HTML and CSS without any external JavaScript functionality or API calls.

---

## 🛠️ Built With

* **HTML5** - For structure and markup elements.
* **CSS3** - For layout styling, card positioning, colors, and visual effects.
